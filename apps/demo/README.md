# Aura Barkod — Canlı Demo

Statik, istemci taraflı demo. Örnek (sample) veri `localStorage` içinde tutulur.

- Gerçek ödeme / SMS / e-posta yok
- Gerçek müşteri verisi yok
- Backend / PostgreSQL / Redis gerekmez

## Yerel çalıştırma

```bash
cd apps/demo
npm install
npm run dev
```
